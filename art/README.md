# Finished art

A PNG here replaces the sprite `tools/art.py` draws for it:
`art/<mod>/<item|block>/<name>.png`, for example `art/vastores/item/tin_ingot.png`
or `art/vastdepths/block/voidium_ore.png`. Use 16x16 RGBA, lit from the top left.
`python3 tools/preview.py build sheet.png` lays every texture out on one sheet.
